# 金融计划收费计算系统

Windows单机财务系统，用于客户与账户管理、账单人工复核、逐账户高水位线（HWM）收费、客户季度Invoice、收款更正及完整数据包交接。

当前源码与正式运行版均为 **1.1.0**，已完成2026-09-18会议的23项需求及正式升级。文档修订：**2026-09-21**。本轮包含三类资金与必需凭证、持仓及独立Closing旗标移除、FC/收费计划Code移除、两处共享导入、客户及资金年季筛选。正式数据根仍为用户确认的 `F:\备份`；源码实现、验收和正式交付见[1.1.0实施](docs/项目说明书.md#meeting-implementation-110)。

2026-09-18会议清单及补充裁决见[本轮需求](docs/项目说明书.md#meeting-20260918)。此前1.0的22项需求、月度编号、首次HWM确认及交付证据继续保留在[1.0交付](docs/项目说明书.md#release-100)，旧测试结果不替代1.1.0验收。

公司解绑、季度组合入口、Excel多计划对应与筛选、付款凭证弹窗和全站选客后显示账户继续保留。此前被策略拒绝的旧运行包/构建/测试目录删除保持暂停，未换工具或改写命令重试；具体范围见主说明书各次发布记录。

## 当前业务与限制

业务链：`基础资料 → 原件人工复核/历史结余与供款加款取款记录 → 逐账户季度结算 → 客户Invoice → 收款/更正 → 导出与全量数据包`。

- 每个Sub Account独立计算HWM和Service Fee，按账户舍入到港币分后汇总；同客户同季度的全部Finalized来源可跨Platform、跨收费计划合并为一张Invoice。
- 各账户HWM收费计划由财务分配，费率默认20%；Company开票收款，FC负责客户介绍及服务。FC缩写和FeePlan Code在1.1.0移除，Company/Platform Code及账单编号规则保持。
- 本地Tesseract OCR与固定`gpt-5.6-sol`只产生候选，人工核对客户、账户、日期、币种、余额及原件后保存历史结余。新流程不提取或确认持仓，历史持仓JSON不改写；云端识别仍由用户主动触发。
- 供款（月供）、加款与取款分开登记，两类流入共同计入净供款。旧CONTRIBUTION仅改网页标签为加款，不回写历史金额、结算或备注。新建三类资金记录必须随记录提交至少一份凭证；手工结余须同时附上至少一张PNG/JPEG图片，可多图。
- 加款说明必填，系统自动附入到账日期、户口和金额，保存备注总长不超过500字符；实际转账当天即到账，作为资金生效日。未锁定更正可换新凭证，旧原件与前后审计保留；旧缺件记录仍可按本条记录补存。
- Closing不再依赖独立资格旗标；同账户历史结余日期仍须等于Closing Date，且限定季末或账户实际退出日。首次HWM确认、后续连续季度继承与锁定保护不变。
- 网页日期显示YYYY年MM月DD日，客户列表移除ID序号；同名候选先用业务身份，仍无法区分时保留必要编号防误选。Platform与Scheme同名时复合标签只显示一次，不修改原字段。
- 新导出内部Excel仅Z列改为计划名称及“Name”副标题；其他日期、金额、公式、编号、既有导出文件及客户双语PDF保持。
- 正式记录通过版本、归档和现金分配台账追踪；首日凭证复验、跳季结算/流水锁定、迟到平台更正已补上回归保护，证据与剩余能力边界见[审查结果](docs/项目说明书.md#gaps)。
- 当前范围是Windows单机稳定使用；Defer、服务器、多用户和通用任意版式OCR不属于已实现能力。

## 开发启动

需要Python 3.12+、Node.js 22.12+及pnpm/corepack。依赖分别由后端锁文件和前端`pnpm-lock.yaml`约束。

```powershell
git clone https://github.com/lch233444/financial-fee-system.git
cd financial-fee-system
./scripts/setup-dev.ps1
./scripts/start-dev.ps1
```

前端开发地址为`http://127.0.0.1:5173`，后端为`http://127.0.0.1:8000/api`。启动前确认端口没有被正式版占用，并使用独立开发数据目录。测试、隔离启动、Windows构建命令见[开发与发布](docs/项目说明书.md#development)；外部二进制准备见[本地构建工具](tools/README.md)。

## 数据与交付边界

正式程序、源码与业务数据分开保存。当前交接登记的正式目录、数据目录和有日期的验证记录见[版本基线](docs/项目说明书.md#state)；路径记录不代表服务此刻正在运行。

服务仅允许loopback。真实客户资料、数据库、附件、识别结果、备份和登录凭据不进入Git。普通开发测试使用隔离合成数据；本地OCR不上传资料，主动运行Sol时图片会发送给OpenAI。日常使用结束直接关闭系统网页；最后一个页面关闭约3秒后后台自动退出，期间新页面连入则继续运行。最小化、切换标签不会触发退出；未提交表单不会自动保存。

每次项目修改同步项目说明书；行为、交付状态或用户确认规则变化同时记录CHANGELOG，具体执行[协作规则](AGENTS.md)。
